# Module 4 – Gate Level Simulation and Synthesis

## Overview

This module covers RTL simulation, synthesis, gate-level concepts and RTL coding caveats.

## Exercises

### 1. Ternary MUX
Implements a 2:1 multiplexer using the ternary operator.

### 2. Bad MUX
Demonstrates the effect of an incomplete sensitivity list.

### 3. Ternary Operator MUX
Demonstrates MUX implementation using the ternary operator.

### 4. Blocking Assignment Caveat
Demonstrates the effect of blocking assignments in RTL.

## Tools Used

- Icarus Verilog
- GTKWave
- Yosys
- GitHub Codespaces

## Verification Flow

1. Write RTL code.
2. Create a testbench.
3. Simulate using Icarus Verilog.
4. Generate VCD waveform.
5. View waveform using GTKWave.
6. Synthesize using Yosys.
7. Check synthesis statistics.

## Key Learning

- Ternary operator
- Multiplexer design
- Sensitivity lists
- RTL simulation
- Blocking assignments
- Synthesis using Yosys
- Gate-level simulation concepts
