# Day 3 – Sequential Logic, Counters & Timing

## Overview

Day 3 focuses on sequential digital logic, clocked circuits, counters, timing concepts and RTL synthesis.

## Topics Covered

- Clock signals
- D Flip-Flop
- Reset operation
- Counter design
- RTL simulation
- GTKWave waveform analysis
- Yosys synthesis

- SKY130 standard-cell library
